# Button TV Glow

The completed, portable version of the Input Sigil button.

Open `index.html` directly or copy the folder into another static site. It has no framework, dependencies, network requests, or project-specific variables.

- 216 independently changing orange background bits in a full 24×9 field;
- 108 independently changing white signal bits in a 36×3 strip;
- a shared, slow power surge across the text and edge-only TV aura;
- terminal typeout, cursor behavior, and reduced-motion fallback.
