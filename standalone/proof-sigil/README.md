# Proof Sigil

A dependency-free, portable version of the Proof Sheet input control.

Open `index.html` directly in a browser or copy the three runtime files into another static site. The control contains:

- a 36×3 field of 108 independently flickering bits;
- an independently regenerating 36×3 field of 108 background bits;
- synchronized, randomized power-surges on `INPUT` and `00 // LOCAL`;
- a typewriter cursor and reduced-motion fallback.

The control is intentionally self-contained: it uses no framework, package, network request, or project-specific CSS variable.
